# 🚀 ShipWith

> **Find your people. Build what’s next.**  
> *A build-first collaboration network for founders, developers, designers, and creators.*

---

## 🌟 Overview

**ShipWith** unifies the fragmented journey of building software and startups:
$$\text{Discover} \longrightarrow \text{Connect} \longrightarrow \text{Trial Build} \longrightarrow \text{Collaborate} \longrightarrow \text{Ship} \longrightarrow \text{Build Passport} \longrightarrow \text{Repeat}$$

Rather than functioning as a passive text resume network or an overwhelming chat server, ShipWith provides **end-to-end execution continuity**:
* **Proof Over Resumes:** Showcase verified GitHub repos, Figma prototypes, and live product demos.
* **The 7-Step Onboarding Engine:** Minimal, Simplify-style onboarding that immediately personalizes your discovery radar.
* **The 5-Day Trial Build:** Time-boxed micro-collaborations to test working compatibility with clear ending decisions (*Continue Together* vs. *End Trial*).
* **The Lightweight Workspace:** Focused alignment room featuring sprint checklists, links, team chat, and daily standups (*"What did you ship today?"*).
* **Permanent Build Passport:** Verifiable contributor roles and peer-reviewed collaboration evidence that cannot be bought with money.

---

## 🛠️ Technology Stack

* **Framework:** React 19 + TypeScript + Vite
* **Styling & Tokens:** Tailwind CSS v4 + Semantic Design Tokens (Substack/Simplify Light + Vercel/Peerlist Dark)
* **Typography:** Manrope (Display), Inter (Body & UI), IBM Plex Mono (Code & Tags)
* **Icons:** Lucide React
* **Accessibility:** WCAG 2.2 AA compliant with full keyboard navigation and focus management

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
