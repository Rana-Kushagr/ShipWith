> **Find your co-founder. Build what actually ships.**  
> *A build-first collaboration network for founders, developers, designers, and creators.*

---

## 🌟 Overview

**ShipWith** unifies the journey of building software and launching high-potential startups:
$$\text{Discovery Radar} \longrightarrow \text{Direct Outreach} \longrightarrow \text{4-Day Trial Sprint} \longrightarrow \text{Workspace Jam} \longrightarrow \text{Verified Build Passport}$$

Rather than relying on self-written resume fluff, follower counts, or cold DMs, ShipWith operates on **verifiable proof of craft**:
* **Proof Over Resumes:** Filter creators and teams by live GitHub repositories, working prototypes, and tangible shipped releases.
* **12-Step Calibration Engine:** Smooth, auto-advancing single-select and multi-select onboarding that instantly tunes your discovery radar across crafts, tech stacks, weekly availability, and equity models.
* **4-Day Scoped Trial Sprint:** Time-boxed micro-collaborations to test working chemistry and code quality on a scoped deliverable before committing equity.
* **Zero Fake Profiles:** 100% authentic human creator network with authentic profiles and clean empty states for genuine project launches.
* **Build Passport:** Verifiable proof-of-work reputation and peer collaboration credentials that stay permanently with you.

## 🛠️ Modern Tech Stack & Design System

* **Framework:** React 19 + TypeScript + Vite 6
* **Styling & Theme Engine:** Tailwind CSS v4 + Semantic Design Tokens
  * *Simplify Light Mode:* Crisp pure white canvas (`#FFFFFF`) with subtle dot grid & ambient gradient mesh
  * *Vercel/Peerlist Dark Mode:* Matte obsidian surfaces (`#09090B`) with hairline borders
* **Typography Pairing:**
  * *Display:* Outfit (`font-display`) for confident, geometric headings
  * *Editorial Serif:* Instrument Serif (`font-serif italic`) for dynamic headline accents
  * *Body:* Plus Jakarta Sans for reading comfort and high contrast
  * *Code / Metrics:* JetBrains Mono (`font-mono`)
* **3D Perspective Stage:** Real-time reversible scroll-driven 3D tilt animation (`rotateX`, `perspective`, `scale`) that resets smoothly when scrolling back to top
* **Icons:** Lucide React (1.5px stroke width)
* **Accessibility:** WCAG 2.2 AA compliant contrast ratios with accessible focus states
